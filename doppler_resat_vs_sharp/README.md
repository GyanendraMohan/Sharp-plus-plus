# Doppler-ResAT vs SHARP

Kaggle notebooks that compare Doppler-ResAT with SHARP's classifier
([francescamen/SHARP](https://github.com/francescamen/SHARP)) on the public SHARP
Doppler traces, under identical data splits, test windows and antenna fusion.

## Input

The SHARP `doppler_traces` dataset (folders `S1a` … `S7a`, files such as
`S1a_E_stream_0.txt`), attached to the notebook as a Kaggle dataset. The notebooks
find it anywhere under `/kaggle/input`. Five classes: empty (E), sitting (L),
walking (W), running (R), jumping (J).

## Notebooks

| Notebook | What it does |
|---|---|
| `notebooks/0_SHARP_readme_pipeline.ipynb` | Runs SHARP's own README pipeline on Kaggle (dataset creation, training, testing, plots), with fixes for the Kaggle disk limit and missing LaTeX. |
| `notebooks/1_LOEO_comparison.ipynb` | Leave-one-environment-out. Fold 1 holds out the bedroom (trains on S6a, S6b, S7a); Fold 2 holds out the living room (trains on S1a–S5a plus S7a). 75/25 time split, test stride 17. Saves training state every epoch and continues across Kaggle sessions. |
| `notebooks/1_LOEO_comparison_colab.ipynb` | The same notebook for Google Colab (downloads the data with a Kaggle token stored in Colab Secrets). |
| `notebooks/2_SHARP_protocol_comparison.ipynb` | SHARP's protocol: S1 split in time 60/20/20; tested on the last 20% of S1 and on S2–S7 at stride 30; seeds 0, 1, 2; also 1–4 antenna subsets. |
| `notebooks/3_ablation.ipynb` | Doppler-ResAT without CBAM and without the BiLSTM layers, under SHARP's protocol (seed 0). Attach notebook 2's output to reuse the full model and SHARP. |

Each model keeps its own training recipe:

- **Doppler-ResAT:** residual CNN (64/128/256) + CBAM + 2 × BiLSTM(128); focal loss,
  AdamW 1e-4, batch 32, up to 25 epochs, early stopping on validation loss
  (patience 10), per-bin z-score from training windows, noise and time-mask
  augmentation, mixed precision, training stride 17.
- **SHARP:** `csi_network_inc_res` from SHARP's `network_utility.py`; Adam 1e-4,
  cross-entropy, early stopping (patience 3), no normalization or augmentation,
  training stride 30.

Both are scored with the same fusion (average of the 4 antennas' probabilities,
then an 11-window moving average). SHARP is also scored with its original majority vote.

All notebooks are generated by `build_notebooks.py`:

```bash
python build_notebooks.py <output_dir>
```

`kaggle/kernel-metadata.example.json` shows how a notebook is pushed with the
Kaggle CLI (`kaggle kernels push -p <folder>`); replace the username and dataset slug.

## Results

| Folder | Contents |
|---|---|
| `results/sharp_protocol/` | `exp1_main.csv` (mean ± std over 3 seeds, smoothed and [unsmoothed]), per-seed results, antenna subsets, confusion matrices, test-window counts, epochs, and per-window predictions (`*.pkl`) |
| `results/loeo/` | `loeo_comparison.csv`, confusion matrices, per-class recall plot, predictions |
| `results/ablation/` | `ablation_main.csv`, `ablation_per_class.csv`, predictions |

Mean recall (%) under SHARP's protocol, mean of 3 seeds (`results/sharp_protocol/exp1_main.csv`):

| Model | S1 | S2 | S3 | S4 | S5 | S6 | S7 |
|---|---|---|---|---|---|---|---|
| SHARP re-run | 99.48 | 99.86 | 99.41 | 97.11 | 87.44 | 99.83 | 91.86 |
| Doppler-ResAT | 100.00 | 99.91 | 99.84 | 99.92 | 92.52 | 99.71 | 84.10 |

LOEO, same folds and windows (`results/loeo/loeo_comparison.csv`), mean recall (%):

| Model | Fold 1 (bedroom held out) | Fold 2 (living room held out) |
|---|---|---|
| SHARP re-run | 83.08 | 99.79 |
| Doppler-ResAT | 80.39 | 96.24 |

Model weights (about 160 MB each) are not included; they exceed GitHub's file size limit.
The `*.pkl` files hold every test window's per-antenna outputs, so all tables can be
recomputed without retraining.
